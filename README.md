# Tyro Logs — Discord бот для логирования событий

[![Discord.js](https://img.shields.io/badge/discord.js-v14-blue.svg)](https://discord.js.org)
[![Node.js](https://img.shields.io/badge/node-%3E%3D16-green.svg)](https://nodejs.org)

Бот для отслеживания и логирования различных событий на Discord-сервере: изменения каналов, ролей, сообщений, участников и других элементов сервера.

## 📋 Возможности

- **13 категорий логирования:**
  - 🎤 Голосовые каналы (подключения, отключения, переходы)
  - 📝 Текстовые каналы (создание, удаление, обновления)
  - 📋 Сообщения (удаление, редактирование, архивация)
  - 👥 Роли (создание, обновление, удаление, назначение)
  - 😀 Эмодзи и стикеры
  - ✅ Реакции
  - 🧵 Треды
  - 👤 Участники (вход/выход, баны, муты, никнеймы)
  - 🏰 Настройки сервера
  - 🗯️ Вебхуки
  - 🔗 Приглашения (инвайты)
  - 📅 События сервера и Stage-сессии
  - ⚙️ Автомодерация

- **Два режима отправки логов:**
  - `Embed` — сообщения в формате embed
  - `Webhook` — отправка через вебхук

- **Мультиязычность:** русский и английский языки
- **Гибкая настройка:** включение/отключение отдельных категорий
- **Игнорирование каналов:** возможность исключить каналы из логирования

## 🚀 Быстрый старт

### Требования

- Node.js >= 16.x
- npm или yarn
- Discord Bot Token

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/nidevseek/tyro-logs.git
cd tyro-logs
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` и заполните его:
```env
DISCORD_TOKEN=your_bot_token_here
```

4. Запустите бота:
```bash
node start.js
```

## ⚙️ Настройка

### Переменные окружения

| Переменная | Описание |
|------------|----------|
| `DISCORD_TOKEN` | Токен вашего Discord бота |
| `WATCH_BOT_ID` | ID бота для мониторинга статуса (опционально) |
| `CHANNEL_ID` | ID канала для уведомлений о статусе (опционально) |
| `PING_USER_ID` | ID пользователя для уведомлений (опционально) |

### Команды

| Команда | Описание | Права |
|---------|----------|-------|
| `/log` | Настройка лог-канала | Administrator |
| `/settings` | Общие настройки бота | Administrator |
| `/lang` | Изменить язык бота | Administrator |
| `/info` | Информация о боте | Все |

## 🗄️ База данных

Бот использует SQLite для хранения настроек:

- `db/settings.db` — настройки логирования по категориям
- `db/logs.db` — общие настройки логов сервера

Таблицы создаются автоматически при первом запуске.
